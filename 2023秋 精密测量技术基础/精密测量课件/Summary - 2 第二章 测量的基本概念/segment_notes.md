# 第二章 测量的基本概念 —— 讲义与备考精要

## Segment 1: 测量的基本术语与概念辨析
- **Segment ID**: S1-Terminology
- **来源**: 课件 P2-P3；课本 P2-P3 (§1-2)；历年期末试卷 Q1
- **核心考点与名词解释**:
  - 计量学 (Metrology): 研究测量，保证量值统一和准确的一门科学。
  - 测量 (Measurement): 为确定被测对象的量值而进行的实验过程。测量结果应包含数值和单位。
  - 测试 (Test): 具有试验性质的测量。也可理解为试验和测量的全过程。
  - 试验 (Experiment): 对产品的特性或性能进行测量、定性或分类所实施的实验。试验对象是特性或性能。
  - 检验 (Inspection): 判断被测物理量是否合格（是否在规定范围内）的过程，通常不一定要求测出具体值。主要对象是工件。
  - 检定 (Verification): 为评定计量器具的计量性能（准确度、稳定度、灵敏度等）并确定其是否合格所进行的全部工作，包含检查、加标记和出具检定证书。主要对象是计量器具（法定性）。
  - 比对 (Comparison): 在规定条件下，对相同准确度等级或指定不确定度范围的同类基准、标准或工作用计量器具复现的量值进行比较的过程。
  - 校准 (Calibration): 在规定条件下，建立测量标准提供的量值与相应示值之间关系的一组操作。
- **核心辨析**:
  - 检验 vs 检定: 检验对象是工件，重在定性合格与否；检定对象是计量器具，具有法定强制性和证书标记。
  - 测量 vs 测试: 测量侧重获取定量量值；测试侧重试验探索特性和规律。

## Segment 2: 测量过程四要素与分类体系
- **Segment ID**: S2-Process-and-Classification
- **来源**: 课件 P4-P13；课本 P2-P3
- **测量基本方程式**: y = f(u)，理想形式 y = Ku（K为比值，u为标准量，y为被测量）。广义长度包含线值、角度、形状、位置和粗糙度等几何量。
- **测量过程四要素**:
  1. 测量对象和被测量 (Object and Measurand): 几何量参数，是设计测量方案的依据。
  2. 测量单位和标准量 (Unit and Standard): 物质体现形式包括光波波长、量块、线纹尺、圆分度盘、光栅/磁栅/容栅等。
  3. 测量方法 (Measurement Method): 器具、条件、操作总和。
  4. 测量精度/不确定度 (Measurement Precision / Uncertainty): 表征测量结果的可靠程度。
- **测量方法核心分类**:
  - 直接测量 vs 间接测量 (Direct vs Indirect): 是否直接读出被测量（卡尺测直径 vs 弓高弦长法测直径）。
  - 绝对测量 vs 相对测量 (Absolute vs Relative): 示值是否直接为被测量全值（钢板尺测长 vs 比较仪以量块调零测微差）。相对测量量程小但精度高。
  - 接触测量 vs 非接触测量 (Contact vs Non-contact): 是否存在接触力和压陷磨损（机械探针 vs 激光干涉/显微镜）。
  - 在线/主动测量 vs 离线/被动测量 (In-process/Active vs Passive): 加工过程中实时监控控制机床 vs 加工完成后终检。

## Segment 3: 测量质量评价指标（期末高频真题）
- **Segment ID**: S3-Performance-Indicators
- **来源**: 课件 P13；课本 P15-P21；考前突击笔记 P3-P5；期末真题 Q2
- **概念辨析**:
  - 精度/精密度 (Precision): 测量结果中随机误差大小的程度，表征多次重复测量值彼此一致的程度（分散性）。
  - 正确度 (Trueness): 测量结果中系统误差大小的程度，表征测量总体均值与真值的偏离程度。
  - 准确度 (Accuracy): 测量结果受随机误差和系统误差综合影响的程度，反映测量值与真值的一致性。
  - 分辨率 (Resolution): 仪器或方法能有效区分两个相邻测量值之间的最小差异。
  - 灵敏度 (Sensitivity): 输出变化量与引起该变化的输入量之比（S = dy/dx），表征响应放大能力。
  - 重复性 (Repeatability): 相同测量条件（同仪器、同人员、同地点、短时间内）多次测量结果的一致性。
  - 重现性 (Reproducibility): 改变测量条件（不同仪器、不同操作者、不同实验室、不同时间）测量结果的一致性。
  - 误差 (Error) vs 不确定度 (Uncertainty): 误差是测量值与真值之差（真值未知，误差不可确知）；不确定度是对测量结果分散性的定量评估，以被测量估计值为中心。
- **经典真题设问**: 选用仪器时在精度（精密度）与准确度之间哪一个指标优先？为什么？
  - 答: 精密度（重复性）优先。原因在于系统误差可以通过标定、对称消除法、代换法或理论模型进行修正和补偿；而随机误差导致的分散性（精密度不高）则无法通过单次测量修正消除。若精密度差，单次测量准确度无从谈起。只有当无法进行系统误差修正且仅做单次绝对测量时，才直接考虑准确度指标。

## Segment 4: 几何量测量四大基本原则
- **Segment ID**: S4-Principles
- **来源**: 课件 P14-P37；课本 P3-P10 (§1-3)
- **4.1 阿贝原则 (Abbé Principle / In-line Principle)**:
  - 定义: 长度测量中，应将被测件尺寸线与标准尺尺寸线沿测量轴线成直线排列（串联布线）。
  - 误差对比: 并联布线（违背阿贝原则）在导轨存在角摆 phi 时产生一次大误差 Delta = s tan phi ≈ s phi；串联布线（符合阿贝原则）仅产生二次微小误差 Delta = l(1 - cos phi) ≈ 0.5 l phi^2。
  - 典型仪器: 游标卡尺（违背）、千分尺（符合）、阿贝测长仪（符合）。
  - 违反时的工程补偿: 减小偏置距 s、提高导轨刚度和直线度减小 phi、光学补偿系统（Eppenstein 光学补偿原理）。
- **4.2 封闭原则 (Closed Principle)**:
  - 原理: 圆周分度封闭，首尾相接的所有分度间隔误差总和必然为零 (sum Delta phi_i = 0)。
  - 应用: 自检法（自测），无需高一级标准器即可测定自身各分度间隔偏差。
  - 方形角尺自检计算: phi_i = alpha + e_i, Delta phi_i = Delta alpha + e_i; 由封闭条件 sum Delta phi_i = 0 得 Delta alpha = -1/n sum e_i, 各直角误差 Delta phi_i = Delta alpha + e_i。
- **4.3 最小变形原则 (Principle of Minimum Deformation)**:
  - 自重变形与最佳支承点:
    - 白塞尔点 (Bessel points): a = 0.2232 L ≈ 2/9 L, b = 0.5536 L，使工件总长度变化最小。
    - 艾利点 (Airy points): a = 0.2113 L ≈ 4/19 L, b = L/sqrt(3) ≈ 0.5774 L，使长工件两端面平行度变化最小（两端切线水平，倾角为零）。
  - 接触变形（赫兹接触理论）:
    - 球对圆柱/球对球: f = K1 * (p^2 (1/d + 1/D))^(1/3)
    - 球对平面: f = K1 * (p^2 / d)^(1/3)
    - 平面对圆柱: f = K2 * (p / l) * (1 / D)^(1/3)
    - 减小措施: 相对测量法（零位与工件两次变形抵消）、控制测量力、优化测头形状、电眼零位微力测头。
  - 热变形控制: 轴向 Delta L = alpha L Delta t。途径包括等温放置、恒温环境、避免手热传导（木夹、手套）。
- **4.4 最短测量链原则 (Principle of Shortest Measurement Chain)**:
  - 从感受被测量到指示装置的转换链（测量链、指示链、辅助链）环节越少，积累误差因素越少，系统可靠性越高。

## Segment 5: 测量方法选择规范与环境控制
- **Segment ID**: S5-Selection-and-Environment
- **来源**: 课件 P38-P47；课本 P3, P10-P12
- **测量方法选择原则**: 满足精度要求的前提下最经济。
- **公差分配、安全裕度与验收极限**:
  - 安全裕度 A: 被测工件对测量不确定度的允许值（通常取公差 T 的 1/3 ~ 1/10）。
  - 验收极限: 从最大实体尺寸 (MML) 和最小实体尺寸 (LML) 分别向工件公差带内缩一个安全裕度 A。
    - 上验收极限 = 最大实体尺寸 - A
    - 下验收极限 = 最小实体尺寸 + A
  - 目的: 防止由于测量误差导致把废品误判为合格品（限制误收率）。
- **基面统一原则**: 测量基面应与设计、工艺、装配基面重合，避免基准不重合误差。
- **温度误差计算模型**:
  - 标准温度: 20 °C。
  - Delta L = L [a1(t1 - 20) - a2(t2 - 20)]
  - 四种工况分析: 当 a1=a2 且 t1=t2 时 Delta L=0，即使温度非 20 °C 也无温度误差；工件与量仪温差是造成温度误差的主要因素。

## Segment 6: 典型案例与习题推导
- **Segment ID**: S6-Cases-and-Problems
- **来源**: 课件 P48-P55；课本 P12-P15 (§1-4), P21 习题 1.1, 1.3
- **圆弧样板非接触测量案例**:
  - 函数关系: R = s^2 / (8h) + h / 2
  - 误差传递: Delta R = (s / (4h)) * Delta s - (s^2 / (8h^2) - 1/2) * Delta h
  - 合成极限误差: Delta_lim R = sqrt( (s/(4h))^2 * Delta_lim s^2 + (s^2/(8h^2) - 1/2)^2 * Delta_lim h^2 )
- **艾利点严格力学推导**: 均布载荷双支承梁，端面转角 theta(0) = 0，由对称性积分得 int_0^(L/2) M(x)dx = 0，解得两支承点间距 b = L / sqrt(3) ≈ 0.5774 L，悬臂长 a = (1 - 1/sqrt(3))/2 L ≈ 0.2113 L。
